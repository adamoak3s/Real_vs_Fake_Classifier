Task 6: Off-the-shelf tools vs. my model¶

Objective: try publicly available tools (Claude, ChatGPT, Gemini, Teachable Machine) on the real-vs-fake problem, report how accurate they are and what makes them hard to use, and compare them with my own model.

Adam Oakes

How the comparison works

  • One fixed sample for everyone: 200 images from the test set (100 REAL, 100 FAKE, chosen at random with a fixed seed), shuffled and renamed img_001 … img_200 so the file names give nothing away. The answer key is in results/task_6/answer_key.csv. The sample, sheets and key are created by prepare_task_6_sample.py.
  • For the chat tools, the images are enlarged 8× (32×32 → 256×256, nearest-neighbor, so no pixels are blended) and arranged on 8 numbered contact sheets in data/task_6_sample/sheets/. Each tool gets the same sheets and the same prompt (data/task_6_sample/PROMPT.txt), with no examples and no information about how many images are fake.
  • Each tool's answers go in results/task_6/predictions/<tool>.csv (columns id,pred). This notebook scores every file it finds there.
  • My model is the best one from Task 5: ImageNet-pre-trained ResNet50, fine-tuned, with horizontal flip and Dropout(0.5). It is scored on the same 200 images and also on the full 20,000-image test set, which no earlier task used.

Metrics: accuracy, plus precision, recall and F1 with FAKE as the positive class, and a confusion matrix. Accuracy alone hides how a tool fails: a tool that calls almost everything REAL can still score well above 50%. With only 200 images, accuracy is uncertain by about ±6 points, so each accuracy is shown with a 95% confidence interval.

My model: fine-tuned ResNet50 (Task 5's best)¶

Task 5 saved only the phase-1 (frozen-base) weights, so the fine-tuning phase is repeated here from those weights, with the same settings, and the result is saved to checkpoints/task_6/. def build_resnet50():
    base = keras.applications.ResNet50(weights=PRETRAINED_WEIGHTS, include_top=False,
                                       input_shape=MODEL_SIZE + (3,))
    inputs = keras.Input(shape=NATIVE_SIZE + (3,))
    x = layers.RandomFlip("horizontal")(inputs)                       # Task 3
    x = layers.Resizing(*MODEL_SIZE, interpolation="bilinear")(x)
    x = layers.Lambda(keras.applications.resnet50.preprocess_input, name="preprocess")(x)
    x = base(x, training=False)
    x = layers.GlobalAveragePooling2D()(x)
    x = layers.Dropout(0.5)(x)                                        # Task 4
    outputs = layers.Dense(1, activation="sigmoid")(x)
    return keras.Model(inputs, outputs, name="resnet50_imagenet"), base

def set_trainable(base, mode):
    base.trainable = mode != "none"
    if mode == "top":
        for layer in base.layers:
            layer.trainable = layer.name.startswith("conv5_")

def fit(model, epochs, lr, train_ds, val_ds):
    model.compile(loss="binary_crossentropy", metrics=["accuracy"],
                  optimizer=keras.optimizers.Adam(learning_rate=lr))
    cb = [keras.callbacks.EarlyStopping(monitor="val_accuracy", patience=3, mode="max",
                                        restore_best_weights=True)]
    return model.fit(train_ds, epochs=epochs, validation_data=val_ds, callbacks=cb, verbose=2)

Add a tool's answers¶

Run the tool on the 8 contact sheets with the prompt in data/task_6_sample/PROMPT.txt, then paste its replies (all sheets, one after another) into save_predictions. It picks out every line that has an image number followed by REAL or FAKE, so extra words in the reply don't matter. A number that never appears is counted as unanswered, and unanswered counts as wrong.

For Teachable Machine, train a model on data/task_6_sample/teachable_machine_train/, export it (Tensorflow.js), and run score_teachable_machine.py; it writes teachable_machine.csv for you.

In my run, claude.csv, gemini.csv and teachable_machine.csv were collected this way. To start over with a fresh sample, run prepare_task_6_sample.py first.

def save_predictions(tool, text):
    found = {}
    for num, lab in re.findall(r"(?<!\d)(\d{1,3})\D{0,12}?\b(REAL|FAKE)\b", text.upper()):
        if 1 <= int(num) <= len(KEY):
            found[int(num)] = lab
    out = pred_dir / f"{tool}.csv"
    pd.DataFrame({"id": sorted(found), "pred": [found[i] for i in sorted(found)]}).to_csv(out, index=False)
    print(f"{tool}: saved {len(found)} of {len(KEY)} answers -> {out.name}")

def metrics(true, pred):
    true, pred = np.asarray(true), np.asarray(pred)
    tp = int(((true == "FAKE") & (pred == "FAKE")).sum()); fn = int(((true == "FAKE") & (pred == "REAL")).sum())
    n_fake = int((true == "FAKE").sum())
    fp = int(((true == "REAL") & (pred == "FAKE")).sum()); tn = int(((true == "REAL") & (pred == "REAL")).sum())
    n = len(true); acc = (tp + tn) / n
    prec = tp / (tp + fp) if tp + fp else float("nan")
    rec = tp / n_fake if n_fake else float("nan")       # an unanswered FAKE image counts as missed
    f1 = 2 * prec * rec / (prec + rec) if prec + rec else float("nan")
    z = 1.96                                             # 95% Wilson interval for accuracy
    centre = (acc + z * z / (2 * n)) / (1 + z * z / n)
    half = z * np.sqrt(acc * (1 - acc) / n + z * z / (4 * n * n)) / (1 + z * z / n)
    return dict(n=n, n_fake=n_fake, accuracy=acc, acc_low=centre - half, acc_high=centre + half,
                precision_fake=prec, recall_fake=rec, f1_fake=f1,
                fake_called_fake=tp, fake_called_real=fn, real_called_fake=fp, real_called_real=tn)

def to_markdown(df):
    f3 = "{:.3f}".format
    lines = ["| tool | images | accuracy (95% CI) | precision (FAKE) | recall (FAKE) | F1 (FAKE) | unanswered |",
             "|---|---|---|---|---|---|---|"]
    for _, r in df.iterrows():
        lines.append(f"| {r.tool} | {r.n:,} | {r.accuracy:.3f} ({r.acc_low:.3f}–{r.acc_high:.3f}) | "
                     f"{f3(r.precision_fake)} | {f3(r.recall_fake)} | {f3(r.f1_fake)} | {r.unanswered} |")
    return "\n".join(lines)

Discussion¶

All tools were scored on the same 200 test images (100 real, 100 fake). With 200 images, each accuracy is uncertain by roughly ±5 points.

Tool Accuracy Precision (FAKE) Recall (FAKE) F1 (FAKE)
My model (fine-tuned ResNet50) 0.990 1.000 0.980 0.990
Teachable Machine 0.865 0.854 0.880 0.867
Claude 0.765 0.873 0.620 0.725
Gemini 0.395 0.200 0.070 0.104

On the full 20,000-image test set, which no earlier task used, my model scored 0.975, in line with its validation accuracy (0.978).

The ranking follows how much each tool learned from this data. My model was fine-tuned on 80,000 labeled images. Teachable Machine trained a small classifier on 1,000 of them, on top of a frozen pre-trained network. The chat tools saw no examples at all and had to rely on general visual judgment.

Accuracy alone hides how the tools fail. Claude recognized 91% of real photos but missed 38% of the fakes. Gemini called only 35 images FAKE, and 28 of those were real: its recall on fakes was 0.07, and its accuracy was below guessing. Teachable Machine's errors were balanced (12% of fakes and 15% of reals).

Challenges: the chat tools get no training signal, resize and re-encode the tiny 32×32 images, need manual uploads and parsing of free-text answers, and are limited in volume (ChatGPT's upload limit stopped the test before it finished). Teachable Machine needs 1,000 manual uploads and has no batch testing, so its model had to be exported and run in code. My model labels 20,000 images in about 15 seconds.

Caveats: one run per tool. Claude designed the sample and knew it was balanced; the other tools were not told. Gemini received all 8 sheets in one message.
